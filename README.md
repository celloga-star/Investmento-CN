# Site de Investimento Celloga

Este projeto é um MVP de plataforma de investimentos, criado para simular retornos com juros compostos e oferecer um painel simples para usuários.

## 🚀 Funcionalidades atuais
- Simulador de investimentos com cálculo de juros compostos
- Histórico de transações
- Interface responsiva em HTML/CSS
- Estrutura inicial organizada (HTML, CSS, JS)

## 🛠 Tecnologias usadas
- HTML
- CSS
- JavaScript

## 📊 Status do projeto
Em desenvolvimento (versão inicial).  
Este é apenas o começo de uma plataforma maior.

## 🔮 Próximos passos
- Adicionar gráficos interativos com **Chart.js**
- Implementar login seguro com **Firebase**
- Integrar pagamentos com **M-Pesa/PayPal**
- Criar histórico persistente para cada usuário
